# 열린국회정보 국회 법안 연결 안내

## 연결 범위

- 공식 출처: [열린국회정보 OpenAPI](https://open.assembly.go.kr/portal/openapi/main.do)
- API: `국회의원 발의법률안`
- 엔드포인트 ID: `nzmimeepazxkubdpn`
- 대상: 대구 지역구 제22대 국회의원 12명
- 결과: 법안 대표발의·공동발의 자료

법안명, 의안번호, 제안일, 제안자, 처리결과와 상세 링크를 읽습니다. 동일 법안이 여러 의원의 조회 결과에 나타나면 의안번호 또는 의안 ID를 기준으로 하나로 합칩니다.

## 샘플 키 실행

1. `collector/국회연결_샘플실행.bat`을 더블클릭합니다.
2. 검은 실행창을 닫지 않습니다.
3. `선이음-동향_실행.html`의 출처 관리에서 `연결 확인`을 누릅니다.
4. 기간을 선택하고 `대구 12명 법안 동기화`를 누릅니다.

열린국회정보의 `sample` 키는 응답 건수가 제한됩니다. 연결 구조 점검용이며 전체 법안 확인용이 아닙니다.

## 정식 발급키 실행

1. 열린국회정보에서 OpenAPI 인증키를 발급받습니다.
2. `collector/국회연결_정식키실행.bat`을 실행합니다.
3. 표시되는 보안 입력창에 키를 붙여넣고 확인합니다.
4. 연결 확인 후 동기화합니다.

키는 실행 중인 Node.js 프로세스의 환경변수에만 전달됩니다. 배포파일, 브라우저 저장공간, 백업 JSON과 콘솔 로그에는 키를 기록하지 않습니다. 실행창을 닫으면 키와 로컬 서비스가 함께 종료됩니다.

## 자료 검토

- 새 자료는 `미확인` 상태로 들어갑니다.
- 수집함에서 `공식 API` 배지를 확인합니다.
- 자동 문장은 API 필드를 조합한 규칙 기반 요약이며 AI 요약이 아닙니다.
- 상세 링크에서 국회 원문을 확인한 뒤 `원문 확인` 또는 `보고서 반영`을 선택합니다.
- API 오류가 일부 의원에게만 발생하면 성공 자료는 보존하고 실패 의원명을 출처 관리에 표시합니다.

## 오류 확인

- `연결할 수 없습니다`: 실행창이 열려 있는지, Node.js 18 이상인지 확인합니다.
- `HTTP 502` 또는 `국회 API 수집 실패`: 인터넷 연결, 인증키, 열린국회정보 서비스 상태를 확인합니다.
- `0건`: 선택 기간에 해당 자료가 없거나 샘플 키의 응답 제한일 수 있습니다.
- 포트 충돌: 환경변수 `SUNEUM_COLLECTOR_PORT`를 바꾸면 현재 v0.3 화면의 기본 주소와 달라지므로, 기본 포트 `3217` 사용을 권장합니다.
