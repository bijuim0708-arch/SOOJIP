# 열린국회정보 국회 법안 연결 안내

## 연결 범위

- 공식 출처: 열린국회정보 OpenAPI
- 대표발의 법안 API: `국회의원 발의법률안`
- 대표발의 엔드포인트 ID: `nzmimeepazxkubdpn`
- 제안자 상세 API: `의안 제안자정보`
- 제안자 엔드포인트 ID: `BILLINFOPPSR`
- 대상: 대구 지역구 제22대 국회의원 12명

현재 연결기는 먼저 대구 의원의 대표발의 법률안을 조회한 뒤, 각 법안의 `BILL_ID`로 `BILLINFOPPSR`를 추가 호출해 대표발의자와 공동발의자 상세를 보강합니다.

법안명, 의안번호, 제안일, 제안자, 처리결과와 상세 링크를 읽고, 제안자정보에서는 의원명·정당·대표발의 구분·의원코드 등 공개 필드를 읽습니다. 동일 법안이 여러 의원 조회 결과에 나타나면 의안번호 또는 의안 ID를 기준으로 하나로 합칩니다.

> 현재 공동발의 연결의 의미는 **대구 의원이 대표발의한 법안의 전체 제안자 명단 보강**입니다. 다른 의원이 대표발의한 법안에 대구 의원이 공동발의자로 참여한 전체 내역을 역검색하는 기능은 별도 확장 단계입니다.

## 연결 진단

1. 열린국회정보에서 OpenAPI 인증키를 발급받습니다.
2. `collector/국회연결_진단.bat`을 실행합니다.
3. 표시되는 보안 입력창에 발급키를 붙여넣고 확인합니다.
4. 진단 결과에서 아래 항목을 확인합니다.
   - `API mode : issued-key`
   - `successful : 12`
   - `proposer API : BILLINFOPPSR`
   - `proposer enriched`가 반환 법안 수와 동일하거나 대부분 성공
   - `proposer failures : 0`이면 정상

인증키는 실행 중인 프로세스의 환경변수에만 전달되고 진단 종료 후 제거됩니다. 키 값은 콘솔에 출력하거나 파일·GitHub·브라우저 저장공간에 기록하지 않습니다.

## 실제 서비스 실행

1. `collector/국회연결_정식키실행.bat`을 실행합니다.
2. 보안 입력창에 발급키를 입력합니다.
3. 검은 실행창을 닫지 않습니다.
4. `선이음-동향_실행.html` 또는 `index.html`의 출처 관리에서 `연결 확인`을 누릅니다.
5. 기간을 선택하고 `대구 12명 법안 동기화`를 실행합니다.

서비스는 기본적으로 `127.0.0.1:3217`에서만 동작합니다. 실행창을 닫으면 키와 로컬 서비스가 함께 종료됩니다.

## 공동발의자 상세 표시

`BILLINFOPPSR` 조회가 성공한 법안에는 다음 정보가 추가됩니다.

- 전체 제안자 수
- 대표발의자 수와 이름
- 공동발의자 수와 이름
- 제안자별 정당명
- 국회의원 코드
- 공동발의자 중 대구 관리대상 의원 여부
- 제안자 명단 100건 도달 시 목록 제한 가능성 표시

수집함의 원문 발췌에는 공동발의자 이름을 일부 표시하고, 전체 명단은 `apiMeta.proposers`에 보존합니다.

## 자료 검토

- 새 자료는 `미확인` 상태로 들어갑니다.
- 수집함에서 `공식 API` 배지를 확인합니다.
- 자동 문장은 API 필드를 조합한 규칙 기반 요약이며 AI 요약이 아닙니다.
- 상세 링크에서 국회 원문을 확인한 뒤 `원문 확인` 또는 `보고서 반영`을 선택합니다.
- 대표발의 조회 또는 제안자정보 조회가 일부 실패하면 성공 자료는 유지하고 실패 내역을 별도로 표시합니다.
- `BILLINFOPPSR` 목록이 100건에 도달한 경우 전체 제안자 명단이 잘렸을 가능성을 염두에 두고 원문을 재확인합니다.

## 오류 확인

- `연결할 수 없습니다`: 실행창이 열려 있는지, Node.js 18 이상인지 확인합니다.
- `ERROR-290`: 인증키가 유효한지 확인합니다.
- `HTTP 502` 또는 `국회 API 수집 실패`: 인터넷 연결, 인증키, 열린국회정보 서비스 상태를 확인합니다.
- `proposer failures`: 대표발의 법안은 수집됐지만 `BILLINFOPPSR` 제안자정보 조회 일부가 실패한 경우입니다.
- `0건`: 선택 기간에 해당 대표발의 법안이 없을 수 있습니다.
- 포트 충돌: 환경변수 `SUNEUM_COLLECTOR_PORT`를 바꾸면 화면의 기본 주소와 달라지므로 기본 포트 `3217` 사용을 권장합니다.
