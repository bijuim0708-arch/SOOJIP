# collector 폴더

대구 관내 공개자료를 수집하는 Node.js 로컬 서비스입니다. 현재 열린국회정보의 `국회의원 발의법률안`과 `의안 제안자정보(BILLINFOPPSR)`를 실제 연결했으며, 나머지 연결기는 빈 모듈입니다.

## 현재 실행

1. Node.js 18 이상을 준비합니다.
2. 열린국회정보에서 OpenAPI 인증키를 발급받습니다.
3. 연결 진단은 `국회연결_진단.bat`을 실행하고 보안 입력창에 발급키를 입력합니다.
4. 실제 서비스 실행은 `국회연결_정식키실행.bat`을 실행하고 보안 입력창에 발급키를 입력합니다.
5. 실행창을 유지한 채 프로그램의 `출처 관리`에서 연결 확인과 동기화를 실행합니다.

서비스는 `127.0.0.1:3217`에만 열립니다. 인증키는 프로세스 환경변수 `SUNEUM_ASSEMBLY_API_KEY`로만 전달되며 HTML·로그·백업파일에 저장하지 않습니다.

`sample` 키는 실제 `국회의원 발의법률안` 호출에서 유효하지 않은 인증키로 거부되는 것이 확인되어 현재 진단 및 실사용 절차에서 사용하지 않습니다.

## 현재 국회 수집 범위

- 대구 지역구 제22대 국회의원 12명의 대표발의 법률안을 조회합니다.
- 각 대표발의 법안의 `BILL_ID`를 이용해 `BILLINFOPPSR` 제안자 명단을 추가 조회합니다.
- 대표발의자·공동발의자 수와 이름, 정당, 의원코드 등 공개 필드를 보강합니다.
- 제안자 명단 중 다른 대구 의원이 있으면 별도 메타데이터로 표시합니다.
- 제안자정보가 100건에 도달한 법안은 API 목록 제한 가능성을 표시합니다.
- 현재 `BILLINFOPPSR` 연결은 **대구 의원이 대표발의한 법안의 제안자 상세 보강** 범위입니다.
- 다른 의원이 대표발의한 법안에 대구 의원이 공동발의자로 참여한 전체 내역을 찾는 역검색은 후속 확장 대상입니다.

## 기본 원칙

- 대구 관내 공개정보만 수집하고 모든 결과에 `regionIds`를 부여합니다.
- API 키·비밀번호·토큰은 HTML이나 데이터 파일에 기록하지 않습니다.
- 출처 하나가 실패해도 다른 출처 수집과 검토 화면은 계속 작동해야 합니다.
- 원문 URL·게시일시·수집일시·출처명·필요한 최소 발췌를 보존합니다.
- 기사 본문 전체를 저장하지 않습니다.
- 원문이나 발언자 식별이 불명확하면 요약을 확정적으로 생성하지 않습니다.
- 각 연결기의 결과는 `connector-interface.js` 공통 필드로 변환합니다.
- 신규 결과는 반드시 `미확인` 상태로 수집함에 넣습니다.

## 연결기 확장 순서

1. 열린국회정보 의안·의원
2. 대구광역시의회와 9개 구·군의회 의사일정·회의록
3. 대구시·9개 구·군 공지·보도·행사
4. 뉴스·블로그 검색
5. 유튜브·SNS

연결 전 출처별 이용약관, API 권한, 호출한도, 저작권 정책과 내부 보안정책을 확인해야 합니다.
