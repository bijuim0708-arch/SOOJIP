선거와 실무를 잇다

선이음-동향 v0.3 사용설명서

선거관리위원회 지도계가 대구 관내의 공개 정치·의정·행사정보를 검토하고 일일보고서 초안을 작성하는 로컬 프로그램입니다. v0.3은 열린국회정보의 국회의원 발의법률안을 실제 연결하는 첫 연결판입니다.

중요: 기본 화면의 기사·동정·회의록·행사 18건과 ‘예시-’ 인물은 가상 예시자료입니다. 출처 관리에서 직접 동기화한 국회 법안만 ‘공식 API’ 배지로 표시됩니다. API 자료도 보고서 반영 전 원문을 확인해야 합니다.

1. 실행 방법

  1. 압축파일을 하나의 폴더에 모두 풀어놓습니다.
  2. 선이음-동향_실행.html을 더블클릭합니다.
  3. Microsoft Edge 또는 Chrome 사용을 권장합니다.
  4. data, assets, collector 폴더의 위치나 이름을 바꾸지 않습니다.

국회 법안 연결을 함께 실행하는 방법

  1. PC에 Node.js 18 이상이 설치되어 있는지 확인합니다.
  2. 시험할 때는 collector/국회연결_샘플실행.bat을 더블클릭하고 열린 창을 닫지 않습니다.
  3. 프로그램의 출처 관리에서 연결 확인을 누른 다음 수집 기간을 선택하고 대구 12명 법안 동기화를 누릅니다.
  4. 전체 응답이 필요하면 열린국회정보에서 인증키를 발급받고 collector/국회연결_정식키실행.bat을 실행합니다. 키는 보안 입력창에만 입력하며 파일에 저장되지 않습니다.
오프라인 사용: 로컬 수집 서비스를 실행하지 않아도 기존 예시자료 검토·보고서·백업 기능은 그대로 작동합니다.

2. 기본 업무 흐름

순서화면담당자 작업
1출처 관리국회 수집 서비스 연결과 동기화 결과를 확인합니다.
2오늘의 동향신규자료·중요자료·향후 일정·수집 실패 출처를 확인합니다.
3수집함자료 구분 배지, 원문 발췌·출처·게시시각을 확인합니다.
4수집함 상세원문 확인, 보고서 반영 또는 제외를 결정합니다.
5의회·회의록발언 원문과 주요부분 요약을 대조합니다.
6일일보고서선택자료의 자동 문장을 수정하고 복사·인쇄·저장합니다.

3. 대구 관할 필터와 인물명부

  • 화면 상단의 관할 필터에서 대구 전체, 대구시, 9개 구·군을 선택합니다.
  • 선택한 관할은 대시보드·수집함·인물·회의록·일정·보고서·출처 화면에 함께 적용됩니다.
  • 인물별 동향의 공식명부는 제22대 국회의원 12명만 우선 등록했습니다. 2026년 지방선거 이후 지방자치단체장·시의원·구·군의원은 각 공식 누리집에서 재확인한 뒤 담당자가 추가합니다.
  • ☆ 중점관리를 누르면 평가나 순위 없이 담당자가 자주 확인할 대상만 따로 모을 수 있습니다.

4. 수집함 사용법

  • 제목·요약·인물·지역을 검색하거나 자료유형, 인물, 중요도, 확인상태로 필터링할 수 있습니다.
  • 카드의 체크상자를 선택하면 여러 자료를 한꺼번에 처리할 수 있습니다.
  • 원문 확인: 담당자가 공개된 원문을 직접 확인한 경우 사용합니다.
  • 보고서 반영: 오늘 보고서에 포함할 자료에 사용합니다.
  • 중복 묶기: 동일 사안을 다룬 기사·보도자료를 2건 이상 선택해 묶습니다.
  • 제외: 보고할 필요가 없거나 중복된 자료를 제외합니다. 원자료 자체는 삭제하지 않습니다.

공식 API 배지는 열린국회정보 응답을 공통 필드로 변환한 자료입니다. 법안 요약은 AI 생성이 아니라 법안명·제안자 필드를 조합한 규칙 기반 문장입니다. 예시 데이터 배지는 실제 자료가 아닙니다.

5. 인물과 출처 관리

인물별 동향 화면에서 관리 대상을 등록·수정·비활성화할 수 있습니다. 출처 관리 화면에서는 공식 홈페이지, 블로그, 의회, 언론검색, SNS 등의 출처를 등록하고 수집방식과 주기를 관리합니다.

사용자가 등록하거나 수정한 정보와 자료별 확인상태는 브라우저 저장공간에 보존됩니다. 원본 예시 데이터 파일을 직접 수정하지 않아도 됩니다.

6. 회의록 검토 원칙

  • 회의명, 회기, 안건명, 발언자, 원문 위치가 확인된 자료만 구체적으로 요약합니다.
  • 발언 원문이 없는 자료는 ‘원문 확인 필요’라고 표시하며 구체적인 발언을 생성하지 않습니다.
  • 요약은 원문을 대신하지 않습니다. 보고서 반영 전 원문과 요약을 대조합니다.

7. 보고서 작성

수집함에서 ‘보고서 반영’한 자료만 보고서 항목에 배치됩니다. 자동 작성된 문장은 보고서 화면에서 직접 클릭해 수정할 수 있습니다.

  • 보고서 복사: 문서작성 프로그램에 붙여넣을 텍스트를 복사합니다.
  • HTML 저장: 현재 보고서 내용을 별도 HTML 파일로 저장합니다.
  • 인쇄: 보고서 부분만 인쇄합니다. 인쇄 창에서 PDF 저장을 선택할 수도 있습니다.

8. 자료 백업과 업데이트

  1. 프로그램 상단의 자료 백업을 눌러 JSON 파일을 저장합니다.
  2. 새 버전 프로그램 폴더를 별도로 준비합니다.
  3. 새 프로그램의 자료 복원을 눌러 백업 JSON을 선택합니다. v0.3은 v0.1·v0.2 백업파일을 자동 변환해 복원할 수 있습니다.
  4. 복원 전 현재 브라우저 자료를 바꿀 것인지 확인창이 표시됩니다.

브라우저 기록을 삭제하거나 다른 PC·브라우저로 이동하면 저장상태가 자동으로 따라가지 않으므로 정기적인 백업을 권장합니다.

9. v0.3에서 아직 연결되지 않은 기능

  • 국회 법안 이외의 의원 일정·발언·표결 자동수집
  • 언론·블로그·지방의회 회의록·지자체 행사 자동수집
  • 유튜브·SNS 인증과 게시물 자동수집
  • AI를 이용한 실시간 원문 요약
  • 로그인, 여러 사용자 간 자료 공유, 서버 저장
  • 외부 전송, 메일 발송, 선거관리시스템 연결
  • 위법 여부나 정치성향의 자동 판정

10. 안전 원칙

  • 공개자료만 사용하고 개인정보·비공개자료·내부 조사자료를 입력하지 않습니다.
  • 프로그램의 요약을 그대로 확정하지 않고 원문·게시시각·출처를 확인합니다.
  • ‘지도계 검토 필요’는 위법 판단이 아니라 담당자 확인이 필요하다는 표시입니다.
  • 최종 보고와 판단은 기존 보고·결재 절차에 따라 담당자가 수행합니다.
  • 언론자료는 기사 본문 전체를 저장하지 않고 제목·언론사·게시일·링크와 업무상 필요한 최소 발췌만 관리합니다.
